A

Conectar Google Sheets

Convertimos una hoja de cálculo en la base de datos. Aquí viven los usuarios, las comisiones y las cotizaciones.

1
Crear una hoja en blanco

Entra a sheets.google.com con tu cuenta de Google y haz clic en el recuadro con el signo + para crear una hoja nueva. Ponle un nombre, por ejemplo SmartScouting datos.

2
Abrir el editor de código

Dentro de tu hoja, abre el menú Extensiones y elige Apps Script. Se abrirá una pestaña nueva con un editor de código.

Extensiones→Apps Script
3
Pegar el código y poner tu clave secreta

Borra todo lo que aparezca en el editor y pega completo el archivo apps_script.gs. Cerca del inicio verás esta línea:

// Debe ser IDÉNTICO al de config.js.
const TOKEN = 'CAMBIA-ESTO-POR-UNA-FRASE-LARGA-Y-SECRETA';

Cámbiala por una frase larga inventada por ti, entre las comillas. Por ejemplo shopx-cuicalli-2026-clave-secreta. Anótala: la vas a necesitar en el paso 6. Guarda con el icono del disquete.

4
Ejecutar «instalar» una vez

Arriba del editor hay una lista de funciones. Elige instalar y presiona Ejecutar. La primera vez Google pedirá permiso para editar tu hoja: acéptalo. Esto crea las tres pestañas y tu cuenta de administrador.

Si vuelves a la hoja verás tres pestañas nuevas abajo: usuarios, configuracion y cotizaciones. Eso confirma que quedó instalado.
5
Publicar como aplicación web

Arriba a la derecha, botón azul Implementar → Nueva implementación. En el engrane elige Aplicación web y configura los dos campos así:

«Cualquier persona» suena abierto, pero sin tu token nadie puede escribir en la hoja. Es normal y necesario para que la app pública pueda conectarse.

Presiona Implementar, autoriza si lo pide, y copia la URL de la aplicación web. Termina en /exec.

6
Pegar los datos en config.js

Abre el archivo config.js del proyecto con un editor de texto y pega las dos cosas: la URL que copiaste y la misma frase del token.

// Antes
const SHEETS_URL = 'TU-URL-DE-APPS-SCRIPT-AQUI';
const SHEETS_TOKEN = 'CAMBIA-ESTO-POR-UNA-FRASE-LARGA-Y-SECRETA';

// Después (con tus datos)
const SHEETS_URL = 'https://script.google.com/macros/s/AKfyc…/exec';
const SHEETS_TOKEN = 'shopx-cuicalli-2026-clave-secreta';
El token de config.js tiene que ser letra por letra igual al del apps_script.gs. Si no coinciden, la app no podrá conectarse.
B

Publicar en Netlify

Con Sheets ya conectado, dejamos la aplicación en línea. Netlify es gratis y no pide tarjeta.

1
Comprimir la carpeta

Asegúrate de que config.js ya tenga tus datos reales. Luego comprime toda la carpeta smartscouting en un archivo .zip (clic derecho → Comprimir).

El archivo apps_script.gs no se usa en el sitio, solo fue para Google. Puedes dejarlo o quitarlo del zip, da igual.
2
Arrastrar a Netlify Drop

Entra a app.netlify.com/drop y arrastra tu .zip a la zona marcada. En unos segundos te da una dirección lista para abrir.

3
Abrir y probar

Netlify te da una dirección tipo nombre-al-azar.netlify.app. Ábrela y entra con tu cuenta de administrador. Si carga y no ves la etiqueta ámbar «Modo local», significa que ya está conectada a Sheets.

Para comprobarlo del todo: da de alta un usuario y luego ábre tu hoja de Google. Debe aparecer una fila nueva en la pestaña usuarios. Ahí confirmas que todo se está guardando en la base.

Y con eso queda en línea

Tu aplicación vive en internet y guarda todo en tu hoja de Google. Desde el módulo de usuarios puedes dar de alta al resto del equipo.
